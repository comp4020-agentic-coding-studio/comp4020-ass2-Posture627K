## The question

Everything so far has built static objects — lines, bigrams, trigrams. What
in this notation actually represents one state becoming another?

## What this builds on

This week stacks two trigrams (weeks 4–7) into a hexagram, then introduces
the mechanism the whole course has been building toward: a changing line,
whose value flips it to its opposite and produces a transformed hexagram.
This is the direct, structural answer to the course's central question, and
the point where the course pivots from constructing signs to studying how
their meanings developed historically.

## Six lines, and the line that isn't fixed

Stack any two trigrams — one below, one above — and the result is a
hexagram: six lines, read bottom to top, with sixty-four possible
combinations at this depth (the same doubling arithmetic from weeks 3–4,
one more level). Which trigram sits below and which sits above is not
interchangeable — Qian-below-Kun and Kun-below-Qian are two different
hexagrams, not the same pair read differently.

The changing-line mechanism is what makes this notation different from a
static combinatorial diagram. A line can be marked as "old" — old yin
(traditionally valued 6) or old yang (valued 9) — rather than merely yin or
yang, and an old line is one that flips: old yin becomes yang, old yang
becomes yin, and the result is a second, transformed hexagram, derived
directly from the first by that single rule. Nothing about which hexagram
comes next is stored anywhere except in the marked line itself — the
transformation is structural, not a separate description bolted onto the
diagram. This is the direct technical answer to the question week 1 opened
with: a state that carries, inside itself, which state it becomes next.

## What you should be able to do after this week

Given a hexagram and a marked changing line (or lines), derive the
transformed hexagram by hand. Assignment 1 (due this week) tests this

arrangements from weeks 6–7 — see the [assessment page](/assessments/) for
